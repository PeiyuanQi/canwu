参伍是一个无界面历史模拟引擎。客户端可以是游戏、研究工具、调试界面或智能体，但它们都通过同一组公开边界访问模拟，而不是取得实时可变世界的引用。

## 工作区 crate

| crate | 核心职责 |
| --- | --- |
| `canwu-core` | 类型化 ID、确定性随机工具和模式元数据 |
| `canwu-time` | 历史时间戳与经过检查的时长运算 |
| `canwu-decision` | 决策票据、确定性求值、控制者与决策策略 SDK |
| `canwu-event` | 通用事件信封、因果来源、受众和结构化事件记录 |
| `canwu-reference-world` | 可替换的示例实体、移动插件、脱离式投影、路由适配器与入门示例 |
| `canwu-knowledge` | 角色知识、来源、可信度与信息时效 |
| `canwu-routing` | 确定性时变路由原语 |
| `canwu-transport` | 运输执行、行程修订、交接、预订与 saga 原语 |
| `canwu-sim` | 私有运行时、调度、插件和结算 |
| `canwu-api` | 通用程序对外 API、规范命令、领域记录、证据与重放 |
| `canwu-information` | 已正式发布的权威信息生命周期扩展 |
| `canwu-correspondence` | 已正式发布的通信模拟领域扩展与模拟插件 |
| `canwu-society` | 已正式发布的社会传播模拟模块 |
| `canwu-culture` | 已正式发布的文化编写、编译与生命周期扩展 |
| `canwu-law` | 已实现的实验性法律编写、制度程序、版本化法律与适用扩展 |
| `canwu-technology` | 已正式发布的证据驱动通用技术模拟扩展 |
| `canwu-history-research` | 可选的下游历史研究评估插件 |
| `canwu-fiscal` | 通用财政程序、地区采纳、核算、执行凭证与持有人相对知识报告扩展 |
| `canwu-ming-fiscal` | 从明初到南明、带出处和完整覆盖矩阵的参考内容包 |
| `canwu-ming-fiscal-reference` | 洪武、万历和弘光可运行财政参考整合 |
| `canwu-debug` | 使用对外 API 与参考世界整合包的参考客户端 |

已正式发布的 `canwu-culture` 文化系统 SDK 建立在 `canwu-society` 之上，不会进入模拟内核。
它把版本化内容编译成外部不可变、绑定内容哈希的执行计划，校验数量与展开后的扇出预算，并提供待处理关系集合
和热目标索引。完整状态记录可以恢复生命周期调度、热/脏索引和效果 cadence。休眠目标离开文化热索引；
上层应用显式同步 society 后会停用其由文化计划编译的转移规则。退休目标还会释放目标相关的动态社会状态并保留历史证据。
边界系统注册、规范化信号准入和增量聚合仍是后续工作。
详见独立的[文化和法律制度系统](/architecture/culture-law/)，其中合并说明文化编写、生命周期和法律制度化设计。

## 从领域扩展到可运行套件

参伍不仅提供内核契约。通用模拟领域扩展提供可复用机制，参考内容包提供可
替换的领域数据，参考整合包把这些能力接入一个小型世界，入门套件则把
它们组合成开发者可以直接运行和改造的纵向切片。这些层都在内核之上，
不会把某个历史世界写入 `canwu-core`。

`canwu-correspondence` 在所有权上是模拟领域扩展：它负责通信需求、地址解析、
接受的路径、遇灾与截取政策，以及跨机制证据；在执行形式上，它同时是一个
`SimulationPlugin`，通过权威命令、规范化输入（canonical ingress）和边界系统接入运行时。
它依赖 `canwu-api` 与 `canwu-information`，反向依赖不存在，因此不会形成依赖环。

参考内容包是数据，不是新的求解器；参考整合包必须使用对外 API，并且
可以被另一种世界或经济模型替换；入门套件必须展示场景创建、命令、结算、
角色相对读取、保存、派生分支和精确重放。内容包和整合包会持续增加，不能被
设计成只有一个固定 Demo 的特殊路径。
