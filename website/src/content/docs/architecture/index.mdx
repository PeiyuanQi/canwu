参伍是一个无界面历史模拟引擎，自身不带渲染器和界面。上层应用（游戏、研究工具、
调试客户端或 AI 智能体）把它当作 Rust 库链接进来，通过提交命令改变世界，通过快照、
事件和角色相对视图读取世界。实时世界状态只由引擎的运行时持有，也只在结算命令和调度
工作时发生变化。

## 分层一览

选择某一层可以查看其中的 crate；切换到“跟随一条命令”，可以一步步看到一条命令从提交到
重放的全过程。

<ArchitectureMap locale="zh-CN" />

- **上层应用**依赖 `canwu-api`，并注册自己需要的插件。
- **领域插件**是建立在 `canwu-api` 之上的可选 crate。第一方扩展能调用的接口与你自己编写的
  插件完全相同，因此任何一个都可以替换。
- **`canwu-api`** 是受支持的对外 API，下层 crate 中需要用到的类型都由它重新导出。
- **`canwu-sim`** 是 `canwu-api` 背后的私有运行时，负责实时状态、输入队列、调度、
  结算、持久化与重放。
- **模型与机制**（`canwu-event`、`canwu-knowledge`、`canwu-decision`、
  `canwu-routing`、`canwu-transport`）定义共用的数据类型，由 `canwu-api` 重新导出。
- **基础层**（`canwu-core`、`canwu-time`）提供 ID、确定性随机数和模拟时间。

## 四条设计规则

1. **状态只通过命令改变。** 客户端提交命令，插件在边界系统中提交变更提议。运行时
   验证两者，并在[结算边界](/architecture/settlement/)中统一提交。
2. **每次运行都可复现。** 时间、调度工作、系统顺序和[随机抽样](/architecture/randomness/)
   都遵循固定规则，所以按日志重放会得到相同的检查点哈希。
3. **知识属于角色。** 运行时把真值与每个角色所知分开保存。玩家和智能体通过
   [角色相对视图](/developer/reading-state/)读取。
4. **历史连同原因一起记录。** 每个[事件](/architecture/events/)都保存起因、受众和
   相关标识，因此可以向引擎查询某件事为什么发生。

## 规则写在哪里

特定时代的规则不写进引擎内核，而是放在 `canwu-api` 之上，分为四种形式：

| 类型 | 提供什么 | 例子 |
| --- | --- | --- |
| 模拟领域扩展 | 以模拟插件形式提供的可复用机制 | `canwu-resource`、`canwu-movement` |
| 参考内容包 | 供扩展使用、带出处的版本化数据 | `canwu-ming-fiscal` |
| 参考整合包 | 组合扩展与内容的小型可运行世界 | `canwu-economy-reference` |
| 入门套件 | 可以复制后修改的可运行示例 | `canwu-reference-world` 中的 `starter` 示例 |

下面几个例子说明职责如何划分：

- **移动。** `canwu-transport` 只保存记录：命令、运输执行、行程修订、交接、预订和运力池。
  `canwu-movement` 是运行这些记录的插件：它准入移动命令，在每个路段到期时结算，分配运力池，
  并把移动报告发给应当收到的角色。事故、危险和敌对行为，以及决定它们的随机抽样，都留在你自己
  的系统中。
- **通信。** `canwu-correspondence` 负责信件从需求到投递的全过程：地址查询、路线、承运人、
  遇灾与截取。它建立在 `canwu-information` 之上，后者负责文书、副本与解读。
- **经济。** `canwu-resource` 负责守恒数量及其履约。`canwu-production` 消耗资源和技术证据，
  驱动设施与工单。`canwu-economy-reference` 把两者与运输、军事补给组合成季节性粮食循环。
  其中的稀缺度和价格压力只是只读投影；只有成交、报价、官价或合同价提供了价格时，它才会报告价格。

跨插件合同（转移清单、动用授权、受托承运人等）各由谁负责，见
[模型归属](/architecture/model-ownership/#领域归属)。

## crate 一览

### 基础层、模型与运行时

| crate | 职责 |
| --- | --- |
| `canwu-core` | 类型化 ID、确定性随机数与 schema 元数据 |
| `canwu-time` | 模拟时间与带溢出检查的时长运算 |
| `canwu-event` | 带起因、受众和结构化字段的事件信封 |
| `canwu-knowledge` | 角色知识，包括来源、可信度与信息时效 |
| `canwu-decision` | 决策票据、控制者、确定性求值与决策策略 SDK |
| `canwu-routing` | 通行时间随时间变化的路线规划 |
| `canwu-transport` | 运输执行、行程修订、交接、预订与运力池的记录类型 |
| `canwu-sim` | 私有运行时：状态、调度、插件、结算、持久化、哈希与重放 |
| `canwu-api` | 对外 API：命令、领域记录、视图、快照、证据与重放 |

### 模拟领域扩展（已发布，可选）

| crate | 职责 |
| --- | --- |
| `canwu-resource` | 资源账户及受保护底线、需求、预留、分配、转移、消费、损耗、动用授权与履约 |
| `canwu-production` | 工艺、生产地点、设施、产能、工单、在制品、项目与产出 |
| `canwu-movement` | 基于 `canwu-transport` 记录的移动命令、路段结算、运力池分配与移动报告 |
| `canwu-military` | 部队、行动、战斗、占领，以及由其他领域结算并确认的待处理效果；游戏需要不同的战斗规则时可以替换 |
| `canwu-society` | 人群之间的社会传播 |
| `canwu-culture` | 文化编写与编译，以及运行在 `canwu-society` 之上的文化生命周期 |
| `canwu-law` | 法律编写、制度程序（包括加权、表决单元与征询阶段）、版本化法律与适用；实验性 |
| `canwu-technology` | 从证据出发的技术模拟：能力、实施、采用与传播 |
| `canwu-fiscal` | 财政程序、地区采纳、核算、执行凭证与按持有人区分的知识报告 |
| `canwu-information` | 文书、副本、访问、发布、解读与真伪判定 |
| `canwu-correspondence` | 按地址投递的信件：需求、地址查询、路线、承运人、遇灾与截取 |
| `canwu-history-research` | 技术模拟的可选历史研究评估插件 |

### 参考内容包（已发布）

| crate | 职责 |
| --- | --- |
| `canwu-ming-fiscal` | 从明初到南明、带出处和覆盖声明的财政内容 |
| `canwu-economy-reference-content` | 经济模型卡、出处与覆盖声明，并明确标出未知和不适用状态 |
| `canwu-military-reference-content` | 供军事扩展使用的版本化合成军事规则集 |

### 参考整合包与工具（仅在仓库中）

| crate | 职责 | 另外依赖 |
| --- | --- | --- |
| `canwu-reference-world` | 小型示例世界（军队、人物、地区、信件）及其移动插件、投影、路由适配器和 `starter` 示例 | 仅 `canwu-api` |
| `canwu-ming-fiscal-reference` | 可运行的洪武、万历、弘光财政场景 | `canwu-fiscal`、`canwu-ming-fiscal`、`canwu-reference-world` |
| `canwu-force-supply-reference` | 作为可替换资源消费者的军事补给，包含征发 saga | `canwu-resource`、`canwu-economy-reference-content` |
| `canwu-economy-reference` | 组合资源、生产、运输、军事补给、稀缺度与价格证据的可运行粮食循环 | `canwu-resource`、`canwu-production`、`canwu-technology`、`canwu-economy-reference-content`、`canwu-force-supply-reference`、`canwu-reference-world` |
| `canwu-military-reference` | 在参考世界中运行的军事扩展及其合成内容 | `canwu-military`、`canwu-military-reference-content`、`canwu-reference-world` |
| `canwu-debug` | 基于对外 API 与参考整合包的桌面调试客户端 | `canwu-reference-world`、`canwu-ming-fiscal-reference` |
