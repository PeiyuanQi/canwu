## 运行

先安装 Git 和 Rust 1.88 或更新版本，再运行：

```shell
git clone https://github.com/PeiyuanQi/canwu.git
cd canwu
cargo run -p canwu-reference-world --example starter
```

首次编译需要几分钟。程序只输出一行：

```text
army_location=3 checkpoint=dd9796a606983d02eafd3495df11b20bb8423cec33f96c0eaddc24e44e4e2de1
```

领地 `3` 是军队的目的地东望城（Eastwatch）。checkpoint 是整个模拟状态的哈希。运行过程是确定性的，再运行一次会得到同样的哈希。

### 1. 构建世界

```rust
let (scenario, ids) = demo_scenario()?;
let plugin = ReferenceWorldPlugin;
let mut canwu = Canwu::new_with_plugins(35, scenario, &[&plugin])?;
```

`demo_scenario()` 返回起始世界 `Scenario`，以及后面要用到的各个 ID。沈将军（General Shen）指挥驻在云都（Yun Capital，领地 2）的第一野战军；从云都经东河道（Eastern River Road）到东望城需要 18 小时。`35` 是随机种子。

世界模型来自 `canwu-reference-world` crate 中的 `ReferenceWorldPlugin`。这个插件把世界存为一条领域记录，并注册 `order_movement_v1` 命令和负责移动军队的边界系统。它只依赖公开的 `canwu-api` crate，你可以换成自己的世界模型。

### 2. 提交命令

```rust
let envelope = order_movement(
    Issuer::Actor(ids.commander),
    &MovementCommand {
        subject: EntityRef::Army(ids.army),
        destination: ids.eastern_territory,
        cargo: Vec::new(),
    },
)?
.at_time(canwu.time());
canwu.enqueue_command(
    canwu.time(),
    0,
    CommandRequest::new(CommandRequestId::new(1), canwu.revision(), envelope),
)?;
```

`order_movement` 把 `MovementCommand` 包装成由沈将军签发的领域命令（`Command::Plugin`），放进 `CommandEnvelope`。`at_time(canwu.time())` 和 `canwu.revision()` 用来拦截过期输入：参伍准入这条请求时，模拟时间和状态版本必须与之一致。

`enqueue_command` 接收到期时间、优先级和请求，把请求放入规范化输入（canonical ingress）。这是一条有记录、有固定顺序的输入路径，重放时会原样读取。

### 3. 推进时间

```rust
canwu.advance_canonical(SimDuration::hours(19))?;
```

`advance_canonical` 结算未来 19 小时内到期的所有边界。边界是一次原子结算，详见[结算系统](/architecture/settlement/)。本次运行共结算三个边界：

| 边界 | 时间 | 发生了什么 |
| --- | --- | --- |
| 1 | Day 0, 00:00 | 命令处理器检查命令、预留这支军队，并安排两个移动数据包：立即出发，18 小时后抵达。 |
| 2 | Day 0, 00:00 | 出发数据包让军队进入行军状态。 |
| 3 | Day 0, 18:00 | 抵达数据包把军队移到东望城。 |

### 4. 保存、加载、派生分支和重放

```rust
let saved = canwu.snapshot_json()?;
let loaded = Canwu::from_snapshot_json_with_plugins(&saved, &[&plugin])?;
let fork = loaded.fork();
let journal = canwu.replay_journal();
let replayed = Canwu::replay_from_journal(&[&plugin], &journal)?;
```

- `snapshot_json` 序列化状态。加载时需要注册同样的插件。
- `fork` 复制一份模拟，副本可以接收不同的输入继续运行。
- `replay_from_journal` 从初始场景和已记录的输入重建整个运行。

示例断言三个副本的检查点哈希都与原运行相同，然后从重放副本中读出军队位置并打印。

## 继续尝试

在 `advance_canonical` 之后打印事件日志：

```rust
for event in canwu.events() {
    println!("{} {} {}", event.timestamp, event.kind.qualified_event_type(), event.summary);
}
```
