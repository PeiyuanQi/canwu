这是理解 Canwu 公开 API 的最短路径：命令不直接修改世界状态，时间由主机显式推进，读取可以是角色相对的。

## 运行

```shell
cargo run -p canwu-api --example move_army
```

## 执行流程

<Steps>
1. 用 `Canwu::demo(35)` 创建确定性的演示世界。
2. 调用 `act()`，以指挥官身份提交 `SemanticAction::MoveArmy`。
3. 用 `advance()` 推进模拟时间，让已计划的到达工作发生。
4. 分别调用 `observe()`，比较指挥官与观察者的知识记录。
</Steps>

## 应该观察什么

- 指挥官在军队到达后立即知道新位置。
- 观察者在报告送达前仍保留旧位置认知。
- 任何世界变化都来自公开的命令/行动边界，而不是可变世界引用。
