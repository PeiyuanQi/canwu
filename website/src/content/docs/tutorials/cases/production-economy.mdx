这个案例不是把《Victoria 3》的市场模型搬进参伍。可借鉴的是“投入、产出、
生产方式、资源条件和物流约束”这组策划语言；参伍实现的是更底层、可替换的
确定性契约，让 CM 自己决定市场、货币、工资、建筑界面和战斗公式。

## 五个交付门槛

| 门槛 | 可运行结果 | 引擎边界 |
| --- | --- | --- |
| G1b | 十四个月合成粮食循环 | 季节收成、种子底线、民食、赈济、军粮、路线关闭、征发后果和下一季反馈 |
| G2 | `canwu-resource` | 守恒账户、需求、预留、精确分配腿、运输交接、验收、消费、损耗和履约 |
| G3 | `canwu-production` | 工艺、生产地点、设施、产能、工单、在制品、执行、项目与产出结算 |
| G4 | `canwu-force-supply-reference` | 独立的军事补给消费者、战备/短缺后果和跨领域征发 saga |

## 生产究竟怎样发生

生产不是“科技已解锁，所以建筑每周自动吐出商品”。一次生产必须通过如下证据链：

```text
修订后的工艺
  + 可用生产地点与设施
  + 材料、劳力/能力、工具/机器、能源
  + 当地技术资格或已安装实现
  + 授权、季节/环境、安全与通行条件
  -> 工单获准并预留产能
  -> 投入进入在制品
  -> 生产执行
  -> 产出经资源扩展结算到账
```

家庭副业、分散作坊、官营作坊、集中工厂和多地点企业都是版本化数据形态，
不是同一条“建筑等级”阶梯。一个游戏可以在上层把它们显示成建筑；引擎只要求
所有投入、能力、设施、时间和产出都有精确版本与可重放结果。

当情景需要表达技术传播和采用较慢时，关键限制不是人为给“时代”加一个低速倍率，
而是把以下环节分开：知道某项技法、具备当地操作资格、把工具/设施安装到某个
地点、为特定用途采用，以及持续获得原料和通行。任何一环缺失，工单都会给出
结构化 blocker，而不会靠年份自动获得能力。

## 地理资源怎样影响生产

参伍不使用一个永恒的 `has_coal = true`。资源内容采用带生效期和出处的能力阶段：

```text
潜在存在 -> 已观察/勘探 -> 已证实 -> 技术可采
         -> 在产地点 -> 路线可达 -> 已运输并验收
```

地质存在不等于可生产。采掘工艺、授权、劳力、设备、能源、治安、道路/水运/铁路
和目的地验收都会改变可用供给。路线规划只给出方案；运输记录行程、容量、执行、
保管权与交接；只有目的地接受以后，资源才可进入当地账户或生产工单。

## 可运行的十四个月粮食循环

第一个 profile 明确标记为 **synthetic**，所有数量都是玩法校准，不是明代人口、
亩产、军粮或价格估计。每月可选择优先赈济、优先军粮、平衡分配或征发军粮。
冬季路线会关闭；秋季收成要保留种子底线；征发会降低合作度，并削弱下一季收成。

```bash
cargo run -p canwu-economy-reference --example grain_loop
cargo test -p canwu-economy-reference
```

资源扩展始终是余额唯一写入者。军队提交需求与消费意图，不能直接扣粮；运输到达
也不等于交付，必须完成交接和验收。这样可以检查每月守恒、失败重试、存档恢复和
精确重放。

## 明代案例：松江棉业原型

历史内容把范围限定为 1450–1644 年松江与长江下游的家庭棉纺织生产。模型支持
“家庭纺纱织布、部分家庭专门承担某一道准备或生产工序，以及商人与经纪组织
流通”这一原型。部分专业作坊生产高档或花式棉布；与此分开，大型城市作坊承担
最后的染色和轧光工序。不能据此推导全明统一工场规模、工资、生产率、现代工厂
系数或全国性组织。

主要模型卡依据 Harriet T. Zurndorfer 对早期近代中国棉纺织制造与市场的研究，
并在内容中记录 PDF 页码定位。该研究把松江的棉业与农户家庭生产、商业化和
分配网络联系起来；参伍据此保留家庭生产与按工序分工的家庭，而不把它改写成一
座时代错置的集中工厂。

## 中国工业化案例：汉阳—大冶—萍乡

第二个历史原型严格标为 **长江中游湖北—江西工业链**，不是“华北工业走廊”：

- 汉阳铁厂位于湖北；
- 大冶铁矿位于湖北；
- 萍乡煤矿位于江西；1896 年的史料能够支持矿务局开始购置矿区和铁路用地，
  但不能据此把当年的线路写成已经投运；
- 1896–1907 年只建模汉阳、大冶和萍乡之间相互关联但尚未合并的前身企业；
  资源能力按有日期的证据节点表达：1896 年为勘察/购地观察，1904 年已有机械化
  平巷投运；铁路 1903 年通至醴陵，1905 年内继续延伸至株洲。由于 fixture 以
  整年为粒度，1906 年才作为“铁路运至株洲、再换装河船运往湖北”的首个完整
  年度代理；各证据节点之间的能力状态不作推断；
- 1908–1911 年才使用合并后的汉冶萍公司组织类别，实际路线可达性仍需独立证据。

内容模型卡引用 Yun Liu 对汉冶萍公司形成的研究、Jeff Hornibrook 对江西萍乡
机械化采煤、地方精英和矿务用地的研究、Elizabeth Perry 对现代矿井及铁路—
水运供应链的梳理，以及 Shellen Xiao Wu 对铁路前水运和 1905 年矿山运行的
材料。这个案例用于测试“矿产能力、采掘
工艺、跨地区路线、能源投入、设施和企业组织如何同时成为约束”，不能外推为
全国代表性、必然的工业化路径、自动技术扩散或统一生产率。

<Aside type="caution" title="历史事实不等于玩法参数">
  两个历史 profile 都是带出处的 archetype，不是完整校准。每个数值和因果规则都
  必须关联模型卡；缺少证据的覆盖单元必须声明为“明确未知”或“不适用”，不能靠
  默认值悄悄补齐。
</Aside>

## 军事与地方经济怎样相互作用

军粮、草料、现银、弹药、备件和燃料保持为不同资源，不能压缩成万能“补给分”。
补给不足产生军队本地的战备、疲劳、凝聚、疾病或逃亡后果。征发造成的民生、
合作度和未来生产影响则通过类型化意图交给经济整合包；经济侧按预期版本应用或
拒绝，再由军队确认，保证双方都不会越权写入对方状态。

## 稀缺与价格

`LocalScarcityProjection` 解释某个持有人实际观察到的库存、需求、缓冲、路线、
治安和政策。它不声称存在价格。只有同一范围和时间段具有成交价、报价、官价或
合同价证据，并有版本化解释规则时，才生成 `PricePressureProjection`。两个投影
都不会创造货币、移动商品、转移所有权或结算交易。
