或来自参考内容中注明出处的资料。

## 运行命令与 crate

| 案例 | 命令 | 主要 crate |
| --- | --- | --- |
| 军阀援军决策 | `cargo run -p canwu-api --example decision_ticket` | `canwu-api` |
| 随机决策与 LLM 选择 | `cargo run -p canwu-api --example uncertainty_resolution` | `canwu-api` |
| 中央赈粮令 | `cargo run -p canwu-api --example governance_transition` | `canwu-api` |
| 社区传播 | `cargo run -p canwu-society --example local_community_diffusion` | `canwu-society` |
| 机密副本 | `cargo run -p canwu-information --example confidential_copy_release` | `canwu-information` |
| 编码截取 | `cargo run -p canwu-information --example encoded_interception` | `canwu-information` |
| 按路线投递的通信 | `cargo run -p canwu-correspondence --example routed_correspondence` | `canwu-correspondence`、`canwu-information` |
| 明代财政 | `cargo run -p canwu-ming-fiscal-reference --example ming_fiscal_starter` | `canwu-fiscal`、`canwu-ming-fiscal`、`canwu-ming-fiscal-reference` |
| 生产经济 | `cargo run -p canwu-economy-reference --example grain_loop` | `canwu-resource`、`canwu-production`、`canwu-economy-reference-content`、`canwu-economy-reference` |

前三个案例只使用[对外 API](/developer/integration/)（`canwu-api`）。其余案例在此基础上
加入一个可选的[模拟领域扩展](/developer/extensions/)，最后两个还用到参考内容包和参考
整合包。具体的历史规则、人物性格和选项生成由应用或其插件定义。
