这里收录情境驱动的完整案例。案例会把多个基础契约组合起来，展示领域包、
controller、policy、权威命令与持久化证据如何协作。

每篇案例都按“要解决的问题、实现方法、代码链接”三部分展开。你可以先理解
使用情境，再沿着系统边界完成实现，最后直接打开可运行源码和验证测试。

`canwu-society` 扩展。具体历史规则、人物性格、情报投影和选项生成仍由应用或
领域插件定义。
