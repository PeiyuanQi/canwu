这里收录情境驱动的完整案例。案例会把多个基础契约组合起来，展示领域包、
controller、policy、权威命令与持久化证据如何协作。

每篇案例都会说明使用情境、所验证的通用机制，以及可运行源码与验证证据的位置。

基础示例只使用公开 `canwu-api`；社会传播示例使用未发布的实验性 `canwu-society`
社会传播模拟模块，在架构上属于建立在公开 API 之上的模拟领域扩展；两个信息流案例
使用未发布的 `canwu-information` 中立模型。具体历史规则、
人物性格、情报投影和选项生成仍由应用或模拟规则插件定义。
