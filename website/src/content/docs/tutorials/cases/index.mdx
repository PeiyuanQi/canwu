controller、policy、权威命令与持久化证据如何协作。

每篇案例都会说明使用情境、所验证的通用机制，以及可运行源码与验证证据的位置。

明代财政案例组合 `canwu-fiscal`、带出处的 `canwu-ming-fiscal` 参考内容包和
`canwu-ming-fiscal-reference` 可运行整合。基础示例只使用公开 `canwu-api`；
社会传播示例使用已正式发布的 `canwu-society`
社会传播模拟模块，在架构上属于建立在对外 API 之上的模拟领域扩展；两个信息流案例
使用已正式发布的 `canwu-information` 中立模型；经路线规划的通信案例使用已正式发布的
`canwu-correspondence` 编排扩展。具体历史规则、
人物性格、情报投影和选项生成仍由应用或模拟规则插件定义。
