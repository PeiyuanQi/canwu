建议从 **移动军队** 开始。它只需要几分钟，在任何装有 Rust 1.88 或更新版本的机器上都能运行，
并完整展示一个周期：提交命令、推进时间，再对这次运行做存档、派生分支和重放。其他教程可以
等到需要对应功能时再看。

## 文档如何组织

| 部分 | 适用情况 | 从这里开始 |
| --- | --- | --- |
| 快速开始 | 第一次使用参伍，想先运行起来 | [移动军队](/tutorials/move-army/) |
| 教程 | 想逐一掌握引擎的核心功能 | [连续时间游戏循环](/tutorials/continuous-game-loop/) |
| 开发指南 | 正在把参伍接入自己的应用，要完成某项具体任务 | [接入并驱动模拟运行](/developer/integration/) |
| 引擎架构 | 想了解命令如何结算、记录和重放 | [架构总览](/architecture/) |
| 领域系统 | 需要知识、资源、移动、战争、技术、赋税或社会方面的规则 | [领域系统](/architecture/systems/) |
| 案例 | 想看几个系统在同一个场景中配合运行 | [案例](/tutorials/cases/) |
| 参考 | 需要查某个概念的规范中英文术语 | [参伍术语表](/reference/terminology/) |

## 领域系统

其中三个系统还有实践教程，对应的设计页面分别是[路线、运输与移动](/architecture/routing-movement/)、
[军事](/architecture/military/)和[技术](/architecture/technology/)。
