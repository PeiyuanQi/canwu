> **推荐玩法：先叫 Agent。** 把这句话交给你的 coding agent：
> “请用 Canwu 做一个能移动军队并推进时间的最小历史模拟，边写边解释关键契约。”
> 让它查阅本教程、开发者指南和公开示例；如果装了 `canwu-engine` 插件，再让它调用 `$canwu-engine-docs`。你当然也可以从头手读——只是滚轮本来没打算转行做考古学家。
