本表规定参伍公开文档中的中英文写法。中文正文使用“中文规范写法”，英文正文使用
English 栏；代码标识始终保持原样。首次出现时可同时给出英文或代码名，例如
**模拟插件**（simulation plugin）或**决策票据**（`DecisionTicket`）。

带链接的术语已有专门页面解释其行为和使用位置；尚未链接的术语目前以本页和 API
文档中的定义为准。仓库中的 Agent 规范来源是
[`docs/terminology.md`](https://github.com/PeiyuanQi/canwu/blob/main/docs/terminology.md)。

每个概念只保留一个公开规范写法。下方的统一写法表会标出已弃用或受限的替代
写法：已弃用写法不应出现在新正文中，受限写法只能在表中说明的技术语境中使用。
现有代码标识和历史记录不因本规则改名。

## 产品与运行时边界

| 中文规范写法 | English | 代码或 API | 含义与使用位置 |
| --- | --- | --- | --- |
| [参伍](/architecture/) | Canwu | `Canwu` | 产品名，也是对外 API 的主要入口；不要把品牌名当作普通名词翻译。 |
| [无界面历史模拟引擎](/architecture/) | headless historical simulation engine | — | 参伍的产品类别；负责模拟历史世界，不负责画面、音频和正式产品界面。 |
| [模拟内核](/architecture/) | simulation core | `canwu-sim` | 持有可变权威状态、调度、结算、持久化与重放的私有运行时。 |
| [上层应用](/developer/integration/) | host application | — | 嵌入参伍的游戏、研究工具、服务、客户端或智能体系统；中文不使用“主机程序”。 |
| [对外 API](/developer/integration/) | public API | `canwu-api` | 应用代码应从这里接入；版本兼容性也以这里为准。 |
| [模拟运行](/developer/persistence/) | simulation run | `run_id` | 具有独立身份、输入、状态和证据的一次连续执行。 |
| [场景](/tutorials/move-army/) | scenario | `Scenario` | 创建模拟时使用的初始世界和配置。 |
| [权威状态](/developer/reading-state/) | authoritative state | `SimulationSnapshot` | 由参伍持有并验证，作为承诺、持久化和重放基础的状态。 |
| [真值](/developer/reading-state/) | ground truth | — | 权威状态中的事实，无论某个角色是否知道。 |
| [角色相对视图](/developer/reading-state/) | actor-relative view | `CanwuViewer`, `ViewerContext` | 根据一个角色的知识和权限（authority）生成的读取结果，不会暴露全知状态。 |
| [只读快照](/developer/reading-state/) | read-only snapshot | `WorldSnapshot` | 供受信任读取使用的脱离运行时状态值，不是实时可变引用。 |

## 时间、输入与结算

| 中文规范写法 | English | 代码或 API | 含义与使用位置 |
| --- | --- | --- | --- |
| [现实时间](/tutorials/continuous-game-loop/) | wall time | — | 上层应用实际经历的时间，不直接写入模拟状态。 |
| [模拟时间](/tutorials/continuous-game-loop/) | simulation time | `SimTime`, `SimDuration` | 由参伍结算、可确定表示的时间。 |
| [表现时间](/tutorials/continuous-game-loop/) | presentation time | — | 客户端动画与插值时间，可以是小数，但不属于权威状态。 |

| [语义动作](/tutorials/move-army/) | semantic action | `SemanticAction` | 面向 UI 或智能体的能力型动作，最终转换成经过验证的命令。 |
| [规范化输入](/architecture/events/) | canonical ingress | `IngressRecord` | 命令、通信、信息和调度系统共用的持久化确定性输入路径。首次出现时可附英文。 |
| [准入](/architecture/events/) | admission | — | 决定哪些待处理输入进入某个边界的过程和切点；它不是 ingress 的同义词。 |
| [调度工作](/architecture/events/) | scheduled work | — | 具有确定模拟到期时间和插入顺序的工作。 |
| [结算边界](/architecture/settlement/) | transaction | `BoundaryRequest`, `BoundaryRecord` | 准入工作、运行系统、记录证据并整体提交或回滚的一次已验证结算边界。 |
| [结算阶段](/architecture/settlement/) | settlement phase | `BoundaryPhase` | 固定边界执行顺序中的一个位置，不代表一套独立结算算法。 |
| [原子提交](/architecture/settlement/) | atomic commit | — | 一次性应用边界中所有通过验证的变化，避免暴露部分状态。 |
| [回滚](/architecture/settlement/) | rollback | — | 边界失败时同时恢复状态、证据、计数器和随机位置。 |

## 插件与扩展

| 中文规范写法 | English | 代码或 API | 含义与使用位置 |
| --- | --- | --- | --- |
| [插件](/developer/extensions/) | plugin | — | 泛称；可能与 Codex 等工具插件混淆时必须加限定词。 |
| [模拟插件](/developer/extensions/) | simulation plugin | `SimulationPlugin` | 实现公开插件契约并注册到参伍运行时的执行单位；其名称、版本和语义哈希标识加载与精确重放所需的可执行语义。 |
| [模拟领域扩展](/tutorials/cases/local-community-diffusion/) | domain extension | — | 建立在公开引擎契约上的可选领域交付包，可包含一个或多个插件、领域类型、schema、命令、查询和辅助 API；没有要求实现的 `DomainExtension` trait。 |
| [模拟模块](/tutorials/cases/local-community-diffusion/) | simulation module | — | 面向人的完整模拟能力名称，例如“社会传播模拟模块”；它可以由一个领域扩展及其插件实现，但本身不是引擎契约。 |
| [技术模拟扩展](/tutorials/technology-diffusion/) | technology simulation extension | `canwu-technology` | 处理技术修订、证据、本地能力、实施、按用途采用和传播机会的可选通用扩展，不是全局科技树。 |
| [历史研究插件](/tutorials/technology-diffusion/) | historical research plugin | `canwu-history-research` | 记录研究者对证据所作有界评估的可选模拟插件，不会改变基础技术真值。 |
| [命令插件](/tutorials/command-plugin/) | command plugin | `register_command()` | 注册带 schema 校验命令及其处理器的模拟插件。 |
| [边界系统](/architecture/settlement/) | boundary system | `BoundarySystemContract` | 在结算阶段运行，并声明读取、写入、资源与随机范围的系统。 |
| [领域 schema](/developer/extensions/) | domain schema | `DomainRecordType` | 插件所拥有领域数据的版本化结构契约；代码相邻的中文正文保留 `schema`。 |
| [领域记录](/developer/extensions/) | domain record | `DomainRecord` | 由插件拥有并持久化，而非属于通用世界模型的类型化领域状态。 |
| 插件组件 | plugin component | `PluginComponentRecord` | 通过声明的键与可见性附加的插件自有组件状态。 |
| [插件语义环境](/developer/persistence/) | plugin semantic environment | `PluginDescriptor` | 加载或精确重放时必须匹配的插件身份、版本和语义哈希集合。 |
| 参考内容包 | reference content pack | — | 由第一方或下游提供的版本化、带命名空间、可序列化领域定义、场景数据、本地化和来源信息包；它向领域扩展提供内容，不是内核子系统或求解器。 |
| 参考整合包 | reference integration | — | 使用公开 API 将通用领域能力映射到小型世界、生产、信息或社会模型的可替换实现；可以包含运行时插件和上层应用适配代码。 |
| 入门套件 | starter kit | — | 将兼容的参考内容包和参考整合包组合成完整纵向切片的可运行宿主与组合示例；它是参考代码，不是特权引擎路径。 |

## 证据、随机性与持久化

| 中文规范写法 | English | 代码或 API | 含义与使用位置 |
| --- | --- | --- | --- |
| [事件](/architecture/events/) | event | `SimEvent` | 权威证据中的可序列化因果记录，不是 UI 通知。 |
| [因果关系](/architecture/events/) | causality | `CauseRef` | 解释事件或变化为何发生的已记录关系。 |

| [资源预留](/tutorials/phased-boundary/) | reservation | `ReservationRequest` | 分配前对守恒资源池提出的声明式申请。 |
| [资源分配](/architecture/settlement/) | allocation | `ReservationAllocation` | 在供给约束下确定性结算竞争申请的结果。 |
| [可见性](/architecture/settlement/) | visibility | `StateVisibility` | 控制状态和证据可以到达哪些读取者的策略。 |
| [快照](/developer/persistence/) | snapshot | `SimulationSnapshot` | 恢复时必须完整校验的持久化状态映像。 |
| [检查点](/developer/persistence/) | checkpoint | `SimulationCheckpoint` | 可与后续日志证据衔接的已验证紧凑基础状态。 |
| [检查点日志](/developer/persistence/) | checkpoint journal | `CheckpointJournal` | 检查点和后续证据的组合，用于紧凑持久化与恢复。代码相邻正文可直接使用类型名。 |
| [精确重放](/developer/persistence/) | exact replay | `replay_from_journal()` | 从已记录输入与证据重建并验证同一次运行，不重新调用外部选择。 |

## 统一写法

| 规范写法 | 已弃用或受限替代写法 | 范围与迁移说明 |
| --- | --- | --- |
| [模拟内核](/architecture/) / simulation core | `kernel` | 受限：产品和接入文档使用 **模拟内核** 与 **simulation core**；`kernel` 可继续用于架构和内部实现说明。 |
| [上层应用](/developer/integration/) / host application | 主机程序 / host program | 已弃用：嵌入参伍的游戏、服务、客户端、研究工具或智能体系统统一使用 **上层应用** 与 **host application**。 |
| [对外 API](/developer/integration/) / public API | public facade | 已弃用：接入边界和整体 API 表面统一使用 **public API**。 |
| [模拟插件](/developer/extensions/) / simulation plugin | 运行时模拟插件 / runtime simulation plugin；模拟规则插件 / domain plugin | 受限：仅在区分运行时插件与 Agent 工具，或说明插件领域角色时使用长写法；它们不是独立插件类别。 |
| [结算边界](/architecture/settlement/) / transaction | settlement boundary | 已弃用：参伍的验证单元英文统一使用 **transaction**；中文规范写法仍为 **结算边界**。 |
| [平行现实](/developer/persistence/) / alternative reality | 反事实分支 / counterfactual branch；branch（因不同输入形成新因果运行时） | 已弃用：不同输入形成的新因果现实统一使用 **平行现实** 与 **alternative reality**；API 操作和复制出的模拟继续使用 **fork**。 |
| [权限](/developer/integration/) / authority | permission（指 `CommandAuthority` 时） | 受限：已验证的行动权统一称为 **权限** 与 **authority**；独立的运行策略上下文继续使用 **permission profile**。 |

## 维护规则

新增或重命名公开概念时，应在同一改动中更新仓库术语表和本页的中英文版本。只有在
对应的专题页面已经存在时才添加链接；在此之前，本术语表本身就是该词的公开定义。
