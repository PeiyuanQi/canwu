本页用于查询参伍术语：中英文名称、对应的代码标识及含义。带链接的术语另有专门页面
详细说明，其余术语以本页和 API 文档中的定义为准。

编写参伍文档时，请在中英文中分别使用表中的规范写法，代码标识保持原样，并避免使用最后
一张表中标为已弃用的写法。首次出现时可以同时给出英文或代码名，例如**模拟插件**
（simulation plugin）或**决策票据**（`DecisionTicket`）。仓库中的
[`docs/terminology.md`](https://github.com/PeiyuanQi/canwu/blob/main/docs/terminology.md)
是术语的权威来源，本页与之同步。
