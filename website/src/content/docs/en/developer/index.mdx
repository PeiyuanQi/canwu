These guides are for developers building a game, research tool, or agent system
on Canwu. Each page covers one task and shows the `canwu-api` calls it needs.

## If this is your first time

1. Run the [move-army tutorial](/en/tutorials/move-army/) to check that your Rust toolchain builds and runs Canwu.
2. Read [Integrate and drive the simulation](/en/developer/integration/) to put the same flow into your own application.
3. Pick the guide below that matches your next task.

## Rules every integration follows

1. **Build on `canwu-api` and published extensions.** Get concrete rules from
   domain extensions such as `canwu-military`, from reference integrations, or
   from your own plugins. Do not depend on internal crates such as `canwu-sim`;
   they carry no compatibility promise.
2. **Change the world through commands.** Use engine commands, domain commands,
   or plugin ingress.
3. **Give players and agents actor-relative views.** Keep full snapshots in
   trusted host code and debugging tools.
4. **Own the clock in your application.** Rendering, input, and wall-clock time
   stay in the host; convert elapsed real time into a simulation duration before
   you call the engine.
5. **Pin versions for saved runs.** Pin the engine version, and load or replay
   with the same plugins. The engine compares them with the plugin descriptors
   stored in the save.
