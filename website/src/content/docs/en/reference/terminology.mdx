This table defines the English and Chinese terms used in Canwu's public
architecture, developer guides, and tutorials. Use the English term in English
prose and the canonical Chinese term in Chinese prose. Keep code identifiers
unchanged.

Linked terms have a focused page that explains their behavior and where to use
them. Unlinked terms are currently defined by this page and the API
documentation. The agent-facing source of truth in the repository is
[`docs/terminology.md`](https://github.com/PeiyuanQi/canwu/blob/main/docs/terminology.md).

Each concept has one preferred public term. The consolidated wording table below
marks alternatives as deprecated or restricted: deprecated terms must not be
introduced in new prose, while restricted terms remain valid only in the stated
technical context. Existing code identifiers and historical records are not
renamed by this policy.

## Product and runtime boundaries

| English | 中文规范写法 | Code or API | Meaning and use |
| --- | --- | --- | --- |
| [Canwu](/en/architecture/) | 参伍 | `Canwu` | Product name and main public API entry point. Do not translate the brand as a generic noun. |
| [headless historical simulation engine](/en/architecture/) | 无界面历史模拟引擎 | — | Canwu's product category: it simulates historical worlds without owning rendering, audio, or production UI. |
| [simulation core](/en/architecture/) | 模拟内核 | `canwu-sim` | The private runtime that owns mutable authoritative state, scheduling, settlement, persistence, and replay. |
| [host application](/en/developer/integration/) | 上层应用 | — | A game, research tool, service, client, or agent system that embeds Canwu. Chinese prose uses 上层应用, not 主机程序. |
| [public API](/en/developer/integration/) | 对外 API | `canwu-api` | The supported API boundary for application code. |
| [simulation run](/en/developer/persistence/) | 模拟运行 | `run_id` | One causally continuous execution with its own identity, inputs, state, and evidence. |
| [scenario](/en/tutorials/move-army/) | 场景 | `Scenario` | The initial world and configuration used to create a simulation. |
| [authoritative state](/en/developer/reading-state/) | 权威状态 | `SimulationSnapshot` | State owned and validated by Canwu and used as the basis for commitments, persistence, and replay. |
| [ground truth](/en/developer/reading-state/) | 真值 | — | Facts present in authoritative state whether or not a particular actor knows them. |
| [actor-relative view](/en/developer/reading-state/) | 角色相对视图 | `CanwuViewer`, `ViewerContext` | A read surface derived from one actor's knowledge and authority rather than omniscient state. |
| [read-only snapshot](/en/developer/reading-state/) | 只读快照 | `WorldSnapshot` | A detached state value for trusted reads, not a mutable reference to the live runtime. |
| simulation granularity | 模拟粒度 | `SimulationGranularity` | A domain-neutral engine level: `aggregate`, `group`, or `actor`. A Celestial Mandate integration may map them to Population, Special Group, and Character. |
| aggregate | 聚合层 | `SimulationGranularity::Aggregate` | Coarse population-, economy-, or region-scale state. A host application may map it to Population. |
| group | 群体层 | `SimulationGranularity::Group` | A bounded social, institutional, military, or organizational group. A host application may map it to Special Group. |
| actor | 角色层 | `SimulationGranularity::Actor` | A person or other principal with knowledge and authority. A host application may map it to Character. |

## Time, input, and settlement

| English | 中文规范写法 | Code or API | Meaning and use |
| --- | --- | --- | --- |
| [wall time](/en/tutorials/continuous-game-loop/) | 现实时间 | — | Real elapsed time observed by the host application. It never enters authoritative state directly. |
| [simulation time](/en/tutorials/continuous-game-loop/) | 模拟时间 | `SimTime`, `SimDuration` | Deterministic, representable time settled by Canwu. |
| [presentation time](/en/tutorials/continuous-game-loop/) | 表现时间 | — | Client-side animation or interpolation time; it may be fractional and is not authoritative. |
| [command](/en/developer/integration/) | 命令 | `Command`, `CommandEnvelope` | A typed request to change authoritative state through structural, precondition, and authority checks. |
| [domain command](/en/tutorials/move-army/) | 领域命令 | `Command::Plugin` | Typed intent defined by a domain integration and validated through public canonical ingress. |
| [canonical ingress](/en/architecture/events/) | 规范化输入 | `IngressRecord` | The persisted, deterministically ordered input path for commands, communication, information, and scheduled systems. |
| [admission](/en/architecture/events/) | 准入 | — | The decision and cut that determine which pending inputs belong to a boundary. It is not a synonym for ingress. |
| [scheduled work](/en/architecture/events/) | 调度工作 | — | Work assigned a deterministic simulation due time and insertion order. |
| [transaction](/en/architecture/settlement/) | 结算边界 | `BoundaryRequest`, `BoundaryRecord` | One validated transaction that admits work, runs systems, records evidence, and commits or rolls back. |
| [settlement phase](/en/architecture/settlement/) | 结算阶段 | `BoundaryPhase` | One position in the fixed boundary execution order, not an independent settlement algorithm. |
| [atomic commit](/en/architecture/settlement/) | 原子提交 | — | Applying all validated boundary changes together so observers never see partial state. |
| [rollback](/en/architecture/settlement/) | 回滚 | — | Restoring state, evidence, counters, and random positions when a boundary fails. |

## Plugins and extensions

| English | 中文规范写法 | Code or API | Meaning and use |
| --- | --- | --- | --- |
| [plugin](/en/developer/extensions/) | 插件 | — | Generic term. Qualify it when confusion with Codex or another tool plugin is possible. |
| [simulation plugin](/en/developer/extensions/) | 模拟插件 | `SimulationPlugin` | A runtime registration unit implementing Canwu's public plugin contract. Its name, version, and semantic hash identify the executable behavior required for loading and exact replay. |
| [domain extension](/en/tutorials/cases/local-community-diffusion/) | 模拟领域扩展 | — | An optional domain-specific delivery package built on public engine contracts. It may contain one or more plugins, domain types, schemas, commands, queries, and supporting APIs. No `DomainExtension` trait is required. |
| [simulation module](/en/tutorials/cases/local-community-diffusion/) | 模拟模块 | — | An informal, human-facing name for a coherent simulation capability, such as the social diffusion simulation module. It may be implemented by an extension and its plugins, but it is not an engine contract. |
| [culture system SDK](/en/architecture/culture-law/) | 文化系统 SDK | `canwu-culture` | A published optional authoring, compilation, and lifecycle extension above `canwu-society`; it validates content and produces a deterministic execution plan without becoming a core subsystem. |
| [legal institutionalization](/en/architecture/culture-law/) | 法律制度化 | `canwu-law` (proposed) | A downstream extension that turns admitted cultural signals into controller-mediated legal proposals and versioned law records; culture never writes legal state directly. |
| [law version](/en/architecture/culture-law/) | 法律版本 | `LawVersion` (proposed) | An immutable, versioned legal rule record with jurisdiction, authority, effective interval, causal references, and enforcement metadata. |
| [compiled culture plan](/en/architecture/culture-law/) | 文化执行计划 | `CompiledCulturePlan` | An externally immutable, content-hash-bound runtime plan containing compact IDs, reverse indexes, budgets, and lifecycle policy compiled from a culture definition. |
| [dormant target](/en/architecture/culture-law/) | 休眠目标 | `Dormant` | A culture target with no engaged population or admitted work that has left hot settlement indexes but retains an explicit reactivation descriptor. |
| [retired target](/en/architecture/culture-law/) | 退休目标 | `Retired` | A culture target removed from hot dynamic state while historical identities and evidence remain available through tombstone and archive contracts. |
| [technology simulation extension](/en/tutorials/technology-diffusion/) | 技术模拟扩展 | `canwu-technology` | The optional generic extension for technique revisions, evidence, local capability, implementation, use-specific adoption, and transmission opportunities. It is not a global technology tree. |
| [historical research plugin](/en/tutorials/technology-diffusion/) | 历史研究插件 | `canwu-history-research` | An optional simulation plugin that records a researcher's bounded assessment of evidence without changing base technology truth. |
| [command plugin](/en/tutorials/command-plugin/) | 命令插件 | `register_command()` | A simulation plugin that registers schema-validated commands and handlers. |
| [boundary system](/en/architecture/settlement/) | 边界系统 | `BoundarySystemContract` | A declared system that runs in a phase with bounded reads, writes, resources, and randomness. |
| [domain schema](/en/developer/extensions/) | 领域 schema | `DomainRecordType` | A versioned structural contract for plugin-owned domain data. Chinese code-adjacent prose retains `schema`. |
| [domain record](/en/developer/extensions/) | 领域记录 | `DomainRecord` | Typed persisted domain state owned by a plugin rather than the generic world model. |
| plugin component | 插件组件 | `PluginComponentRecord` | Plugin-owned component state attached through declared keys and visibility. |
| [plugin semantic environment](/en/developer/persistence/) | 插件语义环境 | `PluginDescriptor` | The exact plugin identities, versions, and semantic hashes required for load or exact replay. |
| reference content pack | 参考内容包 | — | A first-party or downstream package of versioned, namespaced, serializable domain definitions, scenario data, localization, and provenance. It supplies content to a domain extension; it is not a kernel subsystem or solver. |
| reference integration | 参考整合包 | — | A replaceable public-API implementation that maps generic domain capabilities to a small world, production, information, or society model. It may contain runtime plugins and host-adapter code. |
| starter kit | 入门套件 | — | A runnable host and composition example that combines compatible reference content and integrations into a complete vertical slice. It is reference code, not a privileged engine path. |

## Consolidated wording

| Preferred term | Deprecated or restricted alternatives | Scope and migration guidance |
| --- | --- | --- |
| [simulation core](/en/architecture/) / 模拟内核 | `kernel` | Restricted: use **simulation core** in product and integration prose; **kernel** remains permitted in architecture and internal implementation descriptions. |
| [host application](/en/developer/integration/) / 上层应用 | host program / 主机程序 | Deprecated: use **host application** and **上层应用** for a game, service, client, research tool, or agent system that embeds Canwu. |
| [public API](/en/developer/integration/) / 对外 API | public facade | Deprecated: use **public API** for the supported application boundary and the broader API surface. |
| [simulation plugin](/en/developer/extensions/) / 模拟插件 | runtime simulation plugin / 运行时模拟插件; domain plugin / 模拟规则插件 | Restricted: use the longer forms only to contrast runtime plugins with agent tools or to describe a plugin's domain role. They are not separate plugin kinds. |
| [transaction](/en/architecture/settlement/) / 结算边界 | settlement boundary | Deprecated: use **transaction** for the validated Canwu unit. |
| [alternative reality](/en/developer/persistence/) / 平行现实 | 反事实分支 / counterfactual branch; branch (when a different input creates a new causal run) | Deprecated: use **alternative reality** for a new causal reality created by divergent input; use **fork** only for the API operation and copied simulation. |
| [authority](/en/developer/integration/) / 权限 | permission (when meaning `CommandAuthority`) | Restricted: use **authority** for the validated right to act; retain **permission profile** for the separate run-policy context. |

## Maintenance rule

When a public concept is added or renamed, update the repository terminology
file and both website language pages in the same change. Add a link only after a
focused website page exists; this terminology table is the public definition
until then.
