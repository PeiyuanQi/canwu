These scenario-driven examples combine several foundation contracts and show how
domain packages, controllers, policies, authoritative commands, and persisted
evidence cooperate.

Each example explains the scenario, the reusable mechanisms it exercises, and
where to find the runnable code and verification evidence.

Foundation examples use the public `canwu-api`; the social-diffusion example uses the
unpublished `canwu-society` extension built on that facade, and the two
information-flow examples use the unpublished neutral `canwu-information`
model. Historical rules, personalities, information projections, and option
generation remain application or domain-plugin responsibilities.
