Each example is a small scenario you run with one `cargo run` command. Its
page describes the scenario, lists the engine pieces it uses, shows what the
program prints, and walks through the code. The historical settings are
illustrative; the data is synthetic or cited in the reference content.

## Commands and crates

| Example | Command | Main crates |
| --- | --- | --- |
| Warlord aid decision | `cargo run -p canwu-api --example decision_ticket` | `canwu-api` |
| Random decisions and LLM selection | `cargo run -p canwu-api --example uncertainty_resolution` | `canwu-api` |
| Central relief order | `cargo run -p canwu-api --example governance_transition` | `canwu-api` |
| Community diffusion | `cargo run -p canwu-society --example local_community_diffusion` | `canwu-society` |
| Confidential copy | `cargo run -p canwu-information --example confidential_copy_release` | `canwu-information` |
| Encoded interception | `cargo run -p canwu-information --example encoded_interception` | `canwu-information` |
| Routed correspondence | `cargo run -p canwu-correspondence --example routed_correspondence` | `canwu-correspondence`, `canwu-information` |
| Ming fiscal | `cargo run -p canwu-ming-fiscal-reference --example ming_fiscal_starter` | `canwu-fiscal`, `canwu-ming-fiscal`, `canwu-ming-fiscal-reference` |
| Production economy | `cargo run -p canwu-economy-reference --example grain_loop` | `canwu-resource`, `canwu-production`, `canwu-economy-reference-content`, `canwu-economy-reference` |

The first three use only the [public API](/en/developer/integration/)
(`canwu-api`). The others add an optional
[domain extension](/en/developer/extensions/) built on that API, and the last
two also use a reference content pack and a reference integration. Historical
rules, personalities, and option generation stay in the application or its
plugins.
