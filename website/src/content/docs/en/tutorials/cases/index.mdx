These scenario-driven examples combine several foundation contracts and show how
domain packages, controllers, policies, authoritative commands, and persisted
evidence cooperate.

Each example follows the same three-part tutorial structure: the problem to
solve, the systems used to implement it, and links to the runnable code and tests.

  <LinkCard
    title="A warlord asks a neighbor for military aid"

    description="Use a DecisionTicket, dynamic options, a utility policy, authority-derived command execution, traces, persistence, and exact replay for a Beiyang-era-style aid decision."
  />
  <LinkCard
    title="Local community diffusion and institutional response"
    href="/en/tutorials/cases/local-community-diffusion/"
    description="Use experimental canwu-society for sparse population distributions, social influence, a DecisionTicket policy, actor estimates, persistence, and exact replay."
  />
</CardGrid>

Foundation examples use the public `canwu-api`; the social-diffusion example uses the
unpublished `canwu-society` extension built on that facade. Historical rules,
personalities, information projections, and option generation remain
application or domain-plugin responsibilities.
