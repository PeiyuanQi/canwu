These scenario-driven examples combine several foundation contracts and show how
domain packages, controllers, policies, authoritative commands, and persisted
evidence cooperate.

Each example explains the scenario, the reusable mechanisms it exercises, and
where to find the runnable code and verification evidence.

The production-economy case composes `canwu-resource`, `canwu-production`,
economy reference content, an independent force-supply consumer, and a runnable
economy integration. The Ming fiscal case composes `canwu-fiscal`, the source-cited
`canwu-ming-fiscal` reference content pack, and the runnable
`canwu-ming-fiscal-reference` integration. Foundation examples use the public
`canwu-api`; the social-diffusion example
uses the published `canwu-society` social diffusion simulation module,
which is architecturally a domain extension built on that public API. The two
information-flow examples use the published neutral `canwu-information`
model; the routed case uses the published `canwu-correspondence`
orchestration extension. Historical rules, personalities, information projections, and option
generation remain responsibilities of the application or domain plugins.
