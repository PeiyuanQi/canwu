> **Recommended route: send in an agent first.** Give your coding agent this prompt:
> “Build the smallest runnable Canwu simulation that can move an army and advance time. Explain each important contract as we go.”
> Have it use this tutorial, the developer guide, and the public examples; if the `canwu-engine` plugin is installed, have it invoke `$canwu-engine-docs`. Reading everything by hand is still allowed—your scroll wheel simply did not apply for an archaeology internship.
