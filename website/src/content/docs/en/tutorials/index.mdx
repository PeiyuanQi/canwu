Start with **Move an army**. It takes a few minutes, runs on any machine with Rust
1.88 or newer, and shows the whole cycle: submit a command, advance time, then
save, fork, and replay the run. Come back to the other tutorials when you need
the feature they cover.

## How these docs are organized

| Section | Use it when | Start with |
| --- | --- | --- |
| Get started | You are new to Canwu and want to run something first | [Move an army](/en/tutorials/move-army/) |
| Tutorials | You want to learn the engine's core features one at a time | [Continuous-time game loop](/en/tutorials/continuous-game-loop/) |
| Guides | You are adding Canwu to your own application and have a specific task | [Integrate and drive the simulation](/en/developer/integration/) |
| Engine architecture | You want to know how commands are settled, recorded, and replayed | [Architecture overview](/en/architecture/) |
| Domain systems | You need rules for knowledge, resources, movement, war, technology, taxes, or society | [Domain systems](/en/architecture/systems/) |
| Case studies | You want to see several systems work together in one scenario | [Case studies](/en/tutorials/cases/) |
| Reference | You need the standard English or Chinese term for a concept | [Canwu terminology](/en/reference/terminology/) |

## Tutorials

These tutorials use only `canwu-api`; Move an army also uses the reference
world. Your application still chooses its renderer, window, input, and game
framework.

## Domain systems

Domain systems supply concrete rules for knowledge, resources, war, taxes, and
more; most are optional crates you register as needed. Three of them also have a
walkthrough, and their design pages are
[Routing, transport, and movement](/en/architecture/routing-movement/),
[Military](/en/architecture/military/), and
[Technology](/en/architecture/technology/).
