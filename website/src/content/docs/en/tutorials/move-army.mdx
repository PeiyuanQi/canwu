This is the shortest path through Canwu's public API: commands do not mutate the world directly, the host advances time explicitly, and reads can be actor-relative.

## Run it

```shell
cargo run -p canwu-api --example move_army
```

## Flow

<Steps>
1. Create a deterministic demo world with `Canwu::demo(35)`.
2. Call `act()` as the commander with `SemanticAction::MoveEntity` and an army subject.
3. Advance simulation time so the scheduled arrival can execute.
4. Call `observe()` for the commander and observer to compare their knowledge records.
</Steps>

## What to notice

- The commander learns the new location as soon as the army arrives.
- The observer retains stale information until a report is delivered.
- Every world change enters through the public command/action boundary, never a mutable world reference.
