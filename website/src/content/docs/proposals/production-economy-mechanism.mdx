## 结论

**状态：已在 0.10.0 交付。** 生产、消费和军事补给继续位于对外 `canwu-api` 之上的可选扩展；粮食、工厂、价格、军队和历史资源地图不进入模拟内核。

Celestial Mandate 早期在 Canwu 0.6 对外 API 上完成了固定合成夹具。0.10.0 的 G1b 进一步使用真实 `canwu-routing` 与 `canwu-transport` 类型运行十四个月粮食循环；G3 生产扩展和 G4 独立军事补给消费者共同证明同一资源边界被两个不同下游领域复用。

因此提取门槛已经满足：`canwu-resource` 与 `canwu-production` 成为可发布的可选扩展；`canwu-force-supply-reference` 与 `canwu-economy-reference` 保持可替换整合包。G5 只提供有证据的本地稀缺度和价格压力读取，不宣称完整市场模拟。

## 所有权

- 模拟内核：命令准入、时间与阶段顺序、预留分配、声明式读写、原子提交、回滚、证据、可见性、存档和重放。
- `canwu-resource`：资源定义、单位、账户、受保护底线、需求、预留、分配、转移、消费、损耗和履约。
- `canwu-production`：工艺、生产地点、设施、产能、工单、在制品、执行、项目和产出结算。
- `canwu-transport`：移动执行、路线腿、容量、保管权交接和交付完成桥接；资源扩展仍拥有在途货物余额、损耗、接受、退回和目的地入账。
- 人口、生产和军事领域：形成需求并消费精确履约结果，不直接改写其他领域的状态。
- 历史内容：地点、资源、工艺、设施、制度、参数和来源；不能获得特权写入路径。

## 已满足的提取门槛

G3 生产与 G4 军事补给是两个独立生命周期所有者，都消费同一套账户、预留、分配、转移和履约语义。生产扩展建立在守恒层之上，并拥有版本化工艺、工单、在制品、维护和设施生命周期；产出仍通过资源扩展入账。

这次交付没有新增模拟内核查询 API，也没有把领域语义下沉。未来完整市场、货币、产权、通用建设或战斗系统仍需新的独立消费者证据和失败夹具，不能由架构图自动获得内核位置。

## 不进入模拟内核的内容

- 历史商品、矿点、农业日历和时代参数；
- 全国统一价格作为物理库存真相；
- 建筑等级、生产方式或科技解锁自动产生地方能力；
- 把路线可达当作预订、发运、到货或可消费；
- 把运输执行记录当作上层应用货物余额与损耗权威。
