## 如何搭配其他文档

- 想先运行代码：从[教程](/tutorials/)开始。
- 想知道主机程序该调用什么、何时调用：留在开发者指南。
- 想理解结算、事件和随机数为什么这样设计：阅读[架构](/architecture/)。
- 想查完整类型和函数签名：查看 `canwu-api` 源码及公开示例。

## 开发者的核心约束

1. 应用代码只依赖 `canwu-api`，不要把内部 crate 当作兼容性接口。
2. 外部修改通过命令、语义动作或规范化 ingress 进入，不直接改写世界状态。
3. 玩家和智能体默认读取角色视角；权威快照只用于受信任的主机逻辑和调试工具。
4. 墙钟、渲染和输入属于主机；Canwu 只接收可表示的模拟时间。
5. 需要存档时固定引擎版本，并在加载和重放时恢复相同的插件语义环境。
