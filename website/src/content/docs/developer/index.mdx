这组文档写给**使用参伍构建产品的开发者**。它不记录项目路线、维护流程、
品牌规范或内部设计提案，而是解释上层应用如何正确使用 `canwu-api`。

## 第一次接入

1. 先运行[移动军队示例](/tutorials/move-army/)，确认本地工具链和对外 API 可以工作。
2. 再阅读[接入并驱动模拟运行](/developer/integration/)，把同一流程放进自己的上层应用。
3. 接入完成后，按需求继续阅读安全读取、存档或插件扩展页面。

## 如何搭配其他文档

- 想先运行代码：从[教程](/tutorials/)开始。
- 想知道上层应用该调用什么、何时调用：留在开发者指南。
- 想理解结算、事件和随机数为什么这样设计：阅读[架构](/architecture/)。
- 想查完整类型和函数签名：查看 `canwu-api` 源码及公开示例。

## 开发者的核心约束

1. 应用代码通过 `canwu-api` 接入；具体领域规则选择参考整合包，不依赖内部 crate 作为兼容接口。
2. 外部修改通过命令、领域命令或其他规范化输入进入，不直接改写世界状态。
3. 玩家和智能体默认读取角色相对视图；只读快照只用于受信任的上层应用逻辑和调试工具。
4. 现实时间、渲染和输入由上层应用负责；参伍只接收能准确表示的模拟时间。
5. 需要存档时固定引擎版本，并在加载和重放时恢复相同的插件语义环境。
