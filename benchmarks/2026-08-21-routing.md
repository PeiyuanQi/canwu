# Routing scale evidence — 2026-08-21

This is a local engineering baseline for the first `canwu-routing.v1` slice,
not a machine-independent service-level objective. It measures deterministic
planning over a synthetic rail network with fixed and scheduled edges. The
benchmark intentionally excludes transport mutation, persistence, and cache
warm-up so those costs are not confused with pure route calculation.

Run it with:

```text
cargo run --release -p canwu-routing --example routing_scale
```

The example prints node count, connection count, iteration count, elapsed
milliseconds, selected leg count, and arrival time. Record the complete output
with the machine, compiler, profile, and date when comparing future changes.
The route cache remains derived and is not included in the authoritative
simulation or replay contract.

## Baseline

- Host: Windows x86_64, AMD Ryzen 7 7800X3D 8-Core Processor
- Compiler: `rustc 1.97.1 (8bab26f4f 2026-07-14)`
- Profile: `--release`
- Workload: 512 nodes, 1,021 connections, 10 cold plans
- Output: `elapsed_ms=260.9512`, `route_legs=256`, `arrival_minutes=766`

This baseline is evidence for later optimization only. It does not promise a
fixed latency across hosts or content packages.
