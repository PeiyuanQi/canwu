# canwu-economy-reference

This unpublished integration composes Canwu's optional resource, production,
reference-content, routing, transport, technology, and force-supply packages.
It provides a runnable G1b grain loop and the detached, holder-bound G5 local
scarcity and evidence-qualified price-pressure projection.

The package is replaceable reference code. It does not add resource,
production, market, or military doctrine to `canwu-sim`, and its synthetic
fixture must not be described as a calibrated historical economy.
