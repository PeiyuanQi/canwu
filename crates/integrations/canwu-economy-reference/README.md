# canwu-economy-reference

This unpublished integration composes Canwu's optional resource, production,
reference-content, routing, transport, technology, and force-supply packages.
It provides a runnable G1b grain loop and the detached, holder-bound G5 local
scarcity and evidence-qualified price-pressure projection.

The package is replaceable reference code. It does not add resource,
production, market, or military doctrine to `canwu-sim`, and its synthetic
fixture must not be described as a calibrated historical economy.

Its settled history leaves the root through the package archive of
`canwu-force-supply-reference`, with the same receipt chain and the same
rule for operations that find no room (`economy_operation_skip` reads the
skip). The archive commit and the acknowledgement that make room advance
the runtime revision, so a host rebuilds a skipped command against the
current revision before it sends it again; the operation ID stays free.
`economy_operation_outcome` reads a settled outcome, hot or archived. An economy commit leaves out an
externality outcome while the force-supply saga that cites it is hot, so a
host that archives both roots archives the force-supply root first.
