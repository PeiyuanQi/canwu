# canwu-economy-reference-content

This Apache-2.0 crate contains immutable, source-linked content used by the
Canwu economy reference packages. It contains no solver, command handler, or
privileged state mutation.

The compiler materializes an explicit coverage cell for every required key.
Coverage resolves only by numeric priority; equal-priority overlaps fail
closed. `explicit_unknown` and `not_applicable` cells cannot contain or
authorize behavior. Every numeric field and causal rule in a supported or
archetype cell cites an exact model card and rule revision. Historical factual
cards carry bounded historical-year windows. Executable gameplay numbers and
rules are sealed on separate uncalibrated synthetic cards unless a numeric
field includes an explicit source derivation.

Three durable fixtures exercise the boundary:

- deliberately synthetic seasonal grain and logistics profiles with distinct
  daily preindustrial-food and six-hour higher-throughput-fuel cadences;
- a 1450-1644 Songjiang/Lower Yangzi household and operation-specialized
  household cotton-production archetype, distributed through merchants and
  brokers and kept distinct from higher-grade cloth workshops and large urban
  dyeing/calendaring workshops;
- 1896-1907 linked Hanyang-Daye-Pingxiang precursor enterprises followed by a
  distinct 1908-1911 consolidated Hanyeping class. The 1896 survey/land
  observation is separate from mechanized adits operating by 1904 and from the
  rail-to-Zhuzhou plus riverboat-to-Hubei chain established after the railway's
  1905 extension. A 1906 start is used only as the first whole-year proxy; no
  continuous capability is inferred between evidence nodes. The 1908 merger
  changes organization rather than creating transport capability. Every class
  remains subject to exact runtime route and delivered-acceptance evidence.

The historical names are scope labels, not claims that all fixture values are
calibrated facts. Each fixture carries top-level disclosures for synthetic,
archetype, disputed, and unknown inputs.
